# Hero Apps (Trustify)

A full-stack web application built with React (Vite), Tailwind CSS, Express.js, and MongoDB. It features a robust application marketplace with dynamic searching, sorting, and pagination (`limit` & `skip`) functionality.

## 🚀 Tech Stack

### Frontend:
- **React 19**
- **Vite 7**
- **Tailwind CSS v4** & **DaisyUI**
- **React Router v7**
- **Recharts & Framer Motion**

### Backend:
- **Node.js & Express.js**
- **MongoDB Atlas**

---

## ✨ Features

- **Dynamic App Marketplace:** Browse through a wide collection of productivity and utility applications.
- **Pagination (`limit` & `skip`):** Efficient data loading and navigation through large datasets using server-side limit and skip parameters.
- **Search & Filtering:** Easily search apps by name and sort them based on various metrics (Ratings, Downloads, Size).
- **Responsive Design:** Fully responsive modern UI built with Tailwind CSS and DaisyUI.
